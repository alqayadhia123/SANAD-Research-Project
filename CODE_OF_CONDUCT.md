# Contributor Covenant Code of Conduct

SANAD contributors and maintainers are expected to maintain a respectful,
professional, and evidence-driven environment.

Examples of unacceptable behavior include harassment, discrimination,
personal attacks, doxxing, threats, and knowingly publishing secrets or
private data.

Project maintainers may remove content, reject contributions, or restrict
participation for conduct that violates this policy.

Report conduct concerns privately to the repository maintainers. Do not
publish sensitive personal information or security vulnerability details
in public issues.

This project is a research proof of concept. Participation does not imply
endorsement, certification, or production suitability.
