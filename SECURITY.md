# Security Policy

## Scope

This repository is a research proof of concept for a driver identity and wallet demonstration using Keycloak and OIDC. It is not a production identity provider, financial wallet, or certified security product.

Security reports should concern vulnerabilities in the code and configuration maintained in this repository. Do not submit real driver records, access tokens, client secrets, passwords, or other personal data in public issues.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** / private security advisory feature for this repository if it is available. If that feature is unavailable, contact the repository maintainer privately through the contact route listed on the maintainer's GitHub profile and ask for a secure reporting channel. Do not assume that a public issue or an unencrypted message is a confidential channel.

Include:
- A concise description and affected commit or file.
- Reproduction steps using synthetic data only.
- Expected and observed behavior.
- Potential impact and any practical mitigations.

## Supported versions

Only the current default branch and explicitly maintained release tags are considered in scope. This policy does not imply a service-level agreement or a guaranteed response time.

## Safe-harbor expectations

Make a good-faith effort to avoid privacy violations, service disruption, destructive testing, and access to data that is not yours. Stop testing and report immediately if you encounter real credentials or personal information.
